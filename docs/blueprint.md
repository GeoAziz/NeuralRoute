# **App Name**: NeuralRoute

## Core Features:

- Static Landing Page: Render the complete portfolio-facing landing page with hero section, navigation, live metrics bar, 'How It Works' steps, benchmark preview, architecture diagram, playground teaser, and footer, utilizing mock data and all specified visual elements and animations.
- Dashboard Display & Metrics: Implement the core dashboard UI, showcasing animated stat cards, detailed provider health panels, and chart visualizations (routing volume, task distribution) with mock data and interactive elements like time range selectors.
- Benchmark Data Visualization: Display the benchmarks page with a filterable heatmap grid, detailed benchmark table (sortable), and provider comparison charts, all populated with realistic mock data and animated transitions.
- Interactive AI Routing Playground: Provide a split-panel playground where users can input prompts, see simulated real-time classification, routing decisions using an AI-like tool, and receive streamed responses (character-by-character animation) with mock data. Includes task override dropdowns and example prompts.
- Paginated Request Log: Render a paginated table of mock request logs with filter, search, and sort functionalities. Allow users to click a row to view a detailed request summary in a sliding drawer.
- Application Settings Management: Implement a settings page UI for mock API key configuration, routing preferences, benchmark scheduling, and 'danger zone' actions with confirmation modals and success/failure toast notifications.
- Global UI Components: Implement global UI components such as a Command Palette (⌘K) for navigation and actions, stackable toast notifications (success, warning, error), consistent empty states, and shimmering loading skeletons across data-driven sections.

## Style Guidelines:

- The default scheme is a dark 'Deep Space' palette. Primary accents use `--primary` (#60a5fa) for CTAs, active states, and links. Secondary accents use `--accent` (#c084fc). Backgrounds vary from page canvas `--bg` (#030712) to `--surface` (#0f1629) for cards and panels, and `--elevated` (#1a2342) for popovers.
- Headlines, page headings, hero display text, and stat numbers utilize 'Inter Tight' (sans-serif) for its bold, impactful presence. Body copy, descriptions, and standard labels use 'Inter' (sans-serif). Code snippets, model names, and the Playground textarea will use 'Geist Mono' (monospace) for a technical feel. Letter spacing and anti-aliasing are applied globally. Note: currently only Google Fonts are supported for 'Inter' and 'Inter Tight'.
- Icons will be sourced from 'Lucide React'. Specific icons for task types (code: `</>`, reasoning: `brain`, summarization: `layers`, extraction: `brackets`, RAG: `document-search`), navigation, status indicators (Status Dot, `✓`, `✗`), and actions (GitHub, Alerts, Search, GPU) will maintain a clean, precise aesthetic matching the overall theme.
- The layout features a fixed 260px sidebar for dashboard navigation, collapsing responsively. Content is presented in full-width, centered sections, utilizing grid structures for stat cards and footer elements. A 4px base unit spacing scale dictates all element margins and paddings. Defined border radii (`--radius-sm`, `--radius-md`, `--radius-lg`, `--radius-xl`) and shadow tokens (`--shadow-sm`, `--shadow-md`, `--shadow-glow-blue`, `--shadow-glow-purple`) are applied consistently.
- Animations are purpose-driven and implemented with Framer Motion, adhering to 'fast-in, slow-out' easing (`cubic-bezier(0.16, 1, 0.3, 1)`). Key animations include page transitions (fade + translateY), number count-ups (stat cards), left-to-right chart data series drawing, subtle glow shadows and translateY on hover for interactive elements, drawer slide-in, command palette scale/fade, toast notifications sliding in, character-by-character typing in the Playground, slow-drifting radial gradients in the hero background, and staggered scroll-reveal effects.
